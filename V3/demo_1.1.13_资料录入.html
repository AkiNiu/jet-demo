资料录入 — 设计说明

设计决策说明

  • 全员共享录入，不做分工 — 资料是厂家标准化文件（合格证/出厂报告/交接报告），翻拍即可，不涉及判定；工作负责人和试验员都可录入任意条目，谁有空谁录
  • 不做合格/不合格判定 — 资料只是照片归档，无判定维度；状态仅 "未录 / 已录" 二态
  • 采集范围 = 抽中设备 — 来源 3.1 抽检对象确认的设备清单，只对抽中设备采集资料（未抽中设备不做）
  • 每设备固定 3 类资料 — 产品合格证 / 出厂试验报告 / 交接试验报告（依据徐州华电真实包裹事实）
  • 双通道入图：拍摄 / 从相册上传 — 纸质原件现场拍；PDF 原件手机打开截屏后从相册上传
  • 操作元数据仅后端留痕 — 谁录的 / 何时录的 / 来源哪里，一线不需要看，只进后端审计日志 + 4.6 督查埋点
  • 默认展开无折叠 — 打开页面所有设备 slot 一览无余，不做折叠交互；用户直接看到还有哪些未录

业务规则摘要

规则说明
采集范围3.1 抽检对象确认后的设备清单（仅抽中设备）
每设备资料固定 3 类：产品合格证 / 出厂试验报告 / 交接试验报告
操作角色工作负责人+试验员均可录入；项目经理只读查看；非本工单无权限
入图通道拍摄照片（应用内取景窗）+ 从相册上传，两者平等
张数限制每 slot 默认单张（标准化文件一般一页足够）
状态未录 / 已录 二态，不做判定
触发3.5 开工会提交完成后入口解锁
合流软合流 4.3 包裹生成（工单级兜底校验，不做设备级守卫）
OCR/离线均不做
