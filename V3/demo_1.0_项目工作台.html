试试以下操作

  • 工作负责人视角：默认落地"进行中" Tab，第一条工单带主色左竖条。横滑 Tab 到"待接收"→ 紫色竖条卡片 → 点击弹确认接收 Bottom Sheet
  • 本次检测流程页 · 工作负责人视角：点击任意"进行中"环节（如检测执行）体验只读监督；点击自己负责的"进行中"环节进操作页面
  • 试验人员视角：进本次检测流程页，点击核查执行/检测执行等自己负责的进行中环节可操作，其他进行中不可操作
  • 项目经理视角：顶部显示"＋"创建入口；默认落地"全部" Tab；点击工单进流程页，进行中环节不可点（需等完成）
  • 部门经理视角：顶部统计条 + 筛选器（点击地市/状态/类型 chip 弹出 Bottom Sheet 下拉选单，选中值后联动刷新统计条+列表+Tab计数）+ 状态 Tab + 工单列表（带负责人）
  • 公司总经理视角：视角暂同部门经理，数据范围扩大到公司级（统计条显示"本公司·江苏省"+更多工单）
  • 流程页顶栏 ⓘ：查看工单详情（V3.1 增加项目历史记录）
开发参考

列表型 vs Dashboard 型 最终选择理由

  • 电力检测业务 = 连续流程工单（非独立任务），用户 90% 场景是"继续做手头工单"，列表型 1 步直达最快
  • 一线用户日常 2-5 条工单，能一眼数过来，不需要色块概览（信息冗余）
  • 领导需要大盘数据 → 用极简统计条（50px）满足，不占用首屏 200px 高
  • 继承 2.4 allSwitchItems 业务习惯，用户认知无迁移成本
  • 单层页面 = 开发成本低、维护简单、跳转少 1 步

工单列表排序规则

  • 一线视角：最近操作时间降序 → 最近接收时间降序 → 派发时间降序 → 工单 ID 字典序
  • 项目经理视角：派发时间降序
  • 领导视角：最近操作时间降序
