项目工作台（BIGA）

工单列表点击卡片直接进入。从项目维度统一管理所有工单和流程进度。

设计决策

  • 项目信息Tab + 本次检测Tab——取消了独立的P3接收确认页和P4工单详情页，全部合并到项目工作台
  • 一个项目可有多个工单——如龙泉家园小区可能有2次检测（2次工单），项目信息Tab展示检测记录列表
  • 工单级操作收纳到Bottom Sheet——点击检测记录弹出操作菜单（查看流程/确认接收/删除工单），菜单项按角色×状态动态生成
  • 本次检测Tab展示BIGA流程进度——卡片网格按核查/检测/包裹三组分组，3态（未开始/进行中/已完成）

业务规则

规则说明
Bottom Sheet菜单（项目经理+已派发）查看检测流程 / 删除工单（红色）
Bottom Sheet菜单（工作负责人+待接收）确认接收 / 查看检测流程
Bottom Sheet菜单（其他情况）仅查看检测流程
删除约束仅已派发未接收可删，创建人+管理员有权限，逻辑删除
流程卡片点击（操作人）进行中→操作页面，已完成→只读回看，未开始→提示"前置环节未完成"
流程卡片点击（非操作人）进行中/已完成→只读视图，未开始→不可点击

试试以下操作

  • 项目信息Tab：切换角色（项目经理/工作负责人），点击不同状态的工单记录，观察Bottom Sheet菜单差异
  • 项目经理+待接收工单：点击 → "删除工单" → 二次确认 → 工单从列表消失
  • 工作负责人+待接收工单：点击 → "确认接收" → 二次确认 → 状态变为"已接收"
  • 本次检测Tab：切换角色看流程卡片的不同点击反馈
