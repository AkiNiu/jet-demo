建设情况确认

工作负责人到场后，核实站房数量/编号/类型，确认配套设施和进线电缆段数——为下游全部环节建立站房数据基础。页面做三件事：①站房编号/类型核实 ②配套设施有/无 ③进线电缆段数。

设计决策说明

  • 从2.4系统38+次点击减少80%+——2.4系统要求16字段×N站房全量录入。3.0只保留下游核查必须的2个字段（编号+类型），其余延后到抽检对象确认时补录
  • 核实+修正，不是从零录入——工单创建时系统已按项目规模自动生成站房记录和默认编号，工作负责人到场后只需对照现场核实。编号对就直接确认，不对才改
  • 确认和改编号是同一个动作——点击站房行→弹出输入框显示当前编号→没问题直接点"确定"（=确认），要改就改完再点"确定"（=修改+确认）。不存在单独的确认按钮
  • 现场只改编号（含数字+符号两部分），类型后缀规范化延后到包裹阶段——"编号"范围包括数字部分（1/P1/A1）和连接符（#/号/空格/-），可一起修改，如"1#"→"P1号"→"A1-"。但"开关站/配电室/合建站/箱变"这类类型后缀本模块不改，因为叫"开关站"还是"开闭所"不影响现场干活；后缀规范化放在 4.3 包裹生成环节做最终交付前一次性全项目统一调整，现场不浪费时间
  • 数据层：类型 code + 编号 独立存储，不预拼接——系统存储层是两个字段：站房类型（4种code，决定下游分组/模板）+ 编号（自由文本，含数字+符号）。显示层按"{编号}{类型后缀}"即时拼接。包裹阶段改"类型后缀"模板时一次配置全局生效，不用逐个站房改
  • 配套设施用"有/无"双按钮，不用勾选框——勾选框的"未勾选"无法区分"用户选了无"还是"用户没看到"。双按钮保证用户一定看过并做了选择
  • 进线段数是项目级的，不是站房维度——"进线电缆段数"指项目外界电源点向本项目送电的进线路数（外界有几路进线就是几段），不是"每个站房自己的进线数"。N段进线实际进入哪些站房由现场人目视判断，无规则可配。因此设计为全局 Radio 一次选择
  • 提交时规模校验不阻断——当前站房数量与工单规模不一致时弹出提醒但允许继续提交（现场实际规模确实可能与工单不同），用户的"继续提交"决策会留痕
  • 提交后全部锁定，兜底在包裹阶段——站房编号是全流程数据源（影响核查/抽检/安措/检测/报告/包裹目录），中间环节修改影响面过大。在包裹导出前由 4.3 包裹模块提供"站房编号校正"功能统一调整
  • 作业期间三方协同，例外通道仅作业后开放——现场执行期间由工作负责人+试验人员+系统三方配合解决异常；提交后的修改通道仅限人员离场后申请（V3.1 做）

管理者视角（廉政/安全/效率）

  • 廉政防漏报——核心风险是工作负责人与施工方串通少录站房/漏选配套/少选进线段数，规避本应做的核查。V3.0 管控基础：规模一致性必提醒+决策留痕、所有变更带时间戳和操作人、提交即锁定。V3.1 基于这些埋点做管理者看板（规模差异率 Top、配套异常项目预警等）
  • 安全间接风险——站房编号错会导致拍照/检测张冠李戴；进线段数漏选会导致电源核查少拍危险状态位。通过同类型编号唯一性校验、三段必填校验、下游数据结构强绑定字段来防范
  • 效率基础——较 2.4 操作量减 80%+；系统自动预生成站房记录；规模差异前置发现（不用等下游才暴露）

业务规则摘要

规则说明
操作角色工作负责人可编辑；其他人员（试验人员/PM）只读
站房列表来源工单创建时按项目规模自动生成，预设默认编号"1#、2#、3#..."，类型后缀由系统按类型默认（开关站/配电室/合建站/箱变）
站房CRUD可新增（选类型→弹编号输入框）、可删除（左滑→二次确认，至少保留1个）、可改编号（点击行→输入框，改整段编号含数字和符号）
编号范围编号 = 数字部分 + 连接符两段（如"1#"、"P1号"、"A1-"、"西1 "），可一起改；类型后缀（开关站/配电室等）不暴露编辑入口
编号唯一性同类型内编号不可重复（含符号一起比较，如"1#"和"1号"视为不同），重复则Toast阻止确认
类型后缀不在本模块改"开关站/开闭所/环网室"后缀由 4.3 包裹生成环节做最终交付前统一调整（全项目一次配置即可生效，不用逐个站房改）
配套设施充电桩+居民设施各必选"有/无"，选"有"→下游核查分工出现对应任务
进线段数项目级Radio（1/2/3段），无默认值必选；对应电源核查N段拍照
提交校验（三段必填）① 全部站房编号已确认 ② 配套设施全部已选 ③ 进线段数已选；未通过滚动高亮+Toast
规模一致性校验与工单规模逐类型对比，不一致弹面板列差异明细，不阻断，用户可"继续提交"（决策留痕）
中断不保留退出重进需重新操作（V3.0 优先简洁，以操作专注度保证准确度）
提交后锁定全部字段不可改；作业中发现错误必须现场重做；兜底走 4.3 包裹阶段"站房编号校正"
引导文案顶部提示"请确认项目全部站房，包括不抽检的"

电源核查V3.0条件显隐（下游影响，由试验负责人在核查执行时操作）

建设情况确认提供进线段数（确定每站房几路进线），试验负责人在电源核查执行时逐路确认电缆状态，系统据此条件显隐拍照项：

上级电源侧状态本地侧状态显示的拍照项
未敷设—跳过，不生成拍照任务
未搭接（悬空）本地也未搭接电缆端子悬空照 + 临时接地线照 + 进线柜分闸照
未搭接（悬空）本地已搭接进线柜分闸照 + 隔离刀闸断开照 + 接地刀闸合闸照
已搭接检修（已挂接地）进线柜分闸照 + 接地刀闸合闸照
