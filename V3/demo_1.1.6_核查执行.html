P1 · 核查分工（简化展示）

工作负责人将6~8项核查任务按人分配给4名试验人员。完整分工交互见独立Demo。

设计决策

  • 按人分配，没有"组"的概念——4张人员卡片+任务chip标签，"先想人再分活"
  • 每项任务只有1个试验负责人——负责判定，其他人可协助拍照
  • 必须全部分配才能提交——提交前强制校验，未分配项高亮提示
  • 本页为简化展示——仅展示分工结果预览，完整交互（添加/移动/取消/提交确认弹窗）见 demo_核查分工.html

业务规则

规则说明
候选人4名试验人员（工作负责人不参与核查）
任务列表基础6项固定 + 充电/居民设施条件出现 = 6~8项
提交后不可修改全员可见+可协同天然缓解分配不合理
默认推荐V3.0不做，V3.1做后台配置默认分工模板

P2 · 核查执行 + 判定

试验人员并行执行6~8项核查任务——拍照留证+整项判定。

设计决策

  • 拍照只留证，判定只有一层——拍照回答"现场长什么样"，不回答"合不合格"。每项核查由试验负责人做一次整体判定（合格/不合格），去掉2.4系统的逐照片判定
  • 电源核查按电缆状态条件显隐——不再固定拍N张照片。执行人先确认上级电源侧状态（未敷设/未搭接/已搭接），再确认本地侧状态，系统据此动态生成对应的具名拍照项。未敷设也需按进线段数拍确认照（证明确实未铺设）
  • 同一页面完成拍照+判定——拍完后快门区域原地替换为判定表单，取景窗和拍照列表始终可见，不跳页
  • 不合格用Bottom Sheet承载——原因勾选+留证拍照在覆盖层中完成，不压缩页面。留证拍照复用同一套取景窗和快门
  • 全部核查项并行，无前置关卡——2.4系统的"电源核查强制关卡"已取消，4人各做各的，干完帮别人

请试试以下操作

  • 电源核查（条件显隐）：点击"电源核查"→ 弹出电缆状态选择 → 选上级状态 → 选本地状态 → 预览拍照项 → 确认后进入拍照模式
  • 普通拍照：点"建设情况"→ 选拍照项 → 按快门连续拍 → 拍满自动跳下一个
  • 查看/删除照片：点击已拍的项 → 展开照片网格 → 点×删除
  • 判定合格：全部至少1张后 → 底部展开判定表单 → 选合格 → 提交
  • 判定不合格：选不合格 → 勾选原因 → 去拍留证照片 → 完成后提交
  • 帮别人拍：点"送电痕迹"（李四负责）→ 拍完显示"等待李四判定"
  • 切换视角：切到"李四视角"看协同效果

P3 · 核查确认

工作负责人审核全部核查结果，逐项确认通过或退回重做。

设计决策

  • 工作负责人独有页面——试验人员不操作P3，只在P2提交判定后等待确认
  • 确认即锁定，退回即清空——确认后永久锁定；退回后照片+判定全部清空，原试验负责人重做
  • 退回原因选填不强制——现场口头沟通更高效，系统不强制填写
  • 非阻塞——不阻塞后续工作（抽检对象确认、安措等），工作负责人抽空确认

请试试以下操作

  • 1. 先去P2完成几项核查并提交判定
  • 2. 回到P3，看到"待确认"的项
  • 3. 点击待确认项 → 查看照片+判定详情
  • 4. 点"确认通过"→ 该项锁定
  • 5. 或点"退回"→ 填写原因（选填）→ 该项清空
  • 6. 回到P2查看退回效果（状态变红，点击显示退回原因）

业务规则

规则说明
确认通过该核查项永久锁定，P2中不可修改
退回照片+判定全部清空，原试验负责人重做。退回原因选填
退回后不改派分工不变，原人重做。改派留V3.1
审核内容判定结果+拍照记录（每slot几张、谁拍的）+不合格原因+留证照片
